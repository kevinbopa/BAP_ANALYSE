# Résumé exécutif

## Vision

`Sports Prediction Engine` est un produit d'intelligence sportive orienté aide à la décision sur les marchés bookmakers. La première version se concentre volontairement sur le football et sur un seul marché : `1X2`.

L'objectif n'est pas seulement de prédire l'issue d'un match, mais de transformer un grand volume d'informations en une liste hiérarchisée d'opportunités potentiellement rentables.

## Proposition de valeur

Le produit permet de :

- centraliser les données sportives utiles ;
- analyser rapidement tous les matchs d'une zone choisie ;
- générer des probabilités comparables au marché ;
- identifier les écarts entre marché et modèle ;
- mettre en avant les meilleurs deals au lieu de noyer l'utilisateur dans des centaines de matchs.

## Problème marché adressé

L'utilisateur qui souhaite exploiter les marchés football fait face à plusieurs difficultés :

- trop de matchs à surveiller ;
- données dispersées ;
- manque d'outil structuré pour comparer son intuition au marché ;
- difficulté à prioriser les opportunités ;
- impossibilité de mesurer objectivement la qualité des décisions prises.

La V1 répond à ce problème par un moteur d'analyse et de ranking centré sur le `1X2`.

## Définition simple du produit

Le produit prend en entrée :

- une zone d'analyse définie par l'utilisateur ;
- des données historiques de football ;
- des statistiques pré-match ;
- des informations de contexte disponibles ;
- des cotes bookmakers `1X2` quand une source de cotes est branchée en plus de TheSportsDB.

Le produit retourne :

- des probabilités `home/draw/away` ;
- des écarts vs marché ;
- des signaux de value ;
- un classement des meilleurs deals.

## Résultat commercial recherché

La V1 doit être suffisamment solide pour être :

- démontrable à des clients ou partenaires ;
- testable sur des historiques mesurables ;
- présentable comme une base de plateforme premium ;
- extensible vers des offres plus avancées.

## Ambition réaliste de la V1

La V1 n'a pas besoin d'être parfaite sur tous les axes pour être crédible. Elle doit surtout démontrer :

- un pipeline de données sérieux ;
- une méthodologie de modélisation propre ;
- une logique de ranking utile ;
- une traçabilité des résultats ;
- une base technique prête pour évoluer.

## Indicateurs de réussite

- couverture suffisante des compétitions ciblées ;
- prédictions cohérentes sur le marché `1X2` ;
- ranking lisible et explicable ;
- mesure claire de la performance historique ;
- démonstration produit exploitable en contexte business.
